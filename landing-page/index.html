The problem isn't the schedule. It's trusting it.

📰

Today

A PDF that's already out of date

Room changes and cancellations get announced in group chats, if at all. By the time you check the PDF, it's already wrong — and you find out by showing up to an empty room.

✅

With SmartTimetable

One schedule that tells you the truth

Every class shows a live status — Confirmed, Room Changed, or Cancelled — and anyone can flag a mismatch in seconds so it gets fixed for everyone else, not just for them.

What it actually does

📅

Weekly schedule list

Every class for the week in one place — time, room, and course — instead of scrolling a static PDF on your phone.

🔍

Search by course or room

Type a course code or room number to find exactly what you need, instantly, without hunting through a table.

🚩

Report a mismatch in seconds

Noticed something wrong? Flag it from the class detail screen — no name or student ID required.

🛠

One dashboard for admin

Reports and status updates land in one place, so fixing the schedule doesn't mean chasing messages across five group chats.

Built for everyone who touches the schedule

🎓

Students

Check today's classes, confirm a room before you walk there, and report an issue the moment you spot one.

👨‍🏫

Lecturers

Post a cancellation or room change once, and every student sees it immediately — no repeat announcements.

💼

Admin & staff

Review incoming reports and update a class's status from one dashboard, with a clear record of what changed and when.
